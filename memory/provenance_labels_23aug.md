# 🏷️ EVERY CLAIM CARRIES ITS PROVENANCE (Rama, 23-Aug-2026) — ADOPTED, IN USE

Apply in **every direction** — Rama's cards, ChatGPT's reviews, my reports.

| label | meaning |
|---|---|
| 🔬 **VERIFIED BY DIRECT MEASUREMENT** | I ran it, at a **named SHA** |
| 📄 **VERIFIED FROM PROVIDED EVIDENCE** | read in a supplied report; ⛔ not independently run |
| 💭 **INFERENCE / INTERPRETATION** | reasoned, ⛔ not measured |
| 👤 **USER / POLICY DECISION** | Rama's, ⛔ nobody else's |

**Why:** *"AI approval is conditional on evidence access and evidence quality"* — the
failure mode is **a reviewer certifying something it could not inspect**.

**How to apply:** write the label BEFORE the claim. ⭐ The label is the check: being forced
to write 💭 prompts *"then what would 🔬 look like?"* — which is the question that
catches the error.

⭐ **Proven on real cases:** *"`N9-10` is recorded against `65b7196`"* was written as fact,
was 💭, and had to be corrected. Conversely 23-Aug's refusal of an unsourceable
*"Rs 35k/5 = Rs 10k"* quote attributed to Rama is the same mechanism working **before** the
error rather than after. See [[feedback-unsourced-promoted-by-repetition-09aug]] and
[[feedback-verify-the-finding-premise]].

⚠️ A 📄 label is **not** a lesser 🔬 — it records that the source was not opened, which is
exactly the EVIDENCE-BLOCKED state the deploy-governance draft names.
