**Effect/blast radius:** margin for the phantom (closed) qty stays in `used` all session → reservable understated → starves sizing; closed-portion realized PnL never books → **daily-loss gate understates losses** (a partial stop-out that should count doesn't) → can trade past the intended daily-loss limit; per-trade PnL understated. Fires on manual partial scale-out, RMS partial squareoff, or broker partial fill on an exit. Uncommon but real; both a capital-accuracy and a safety-control (daily-loss) impact.
