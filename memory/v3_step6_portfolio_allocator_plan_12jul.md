**The plan (P1-P10):**
- **P1 seam:** ONE seam = the PREPARE→ADMIT boundary in `_process_one`. Extract the ADMIT block (`:919-960`) into a callable both the fused OFF path and a batch worker invoke. PREPARE (pre-flight→strategy→screen→size, ends `:904`) stays 5-worker-concurrent. NOT a parallel allocator — same `approve`/`reserve`/`_enforce_strategy_position_cap`, just driven by the batch worker under enforce.
- **P2 window:** candle-aligned + short drain tail (a few s), ≪ 60s expiry. Reuse `CandleStore.register_on_candle_close` OR a wall-clock-aligned monotonic timer (recommend timer, scope-independent). **Scope: SHADOW observes ALL (15 scanners + V3); ENFORCE v1 = V3-path ONLY** (scanners keep FCFS, read as prior exposure); full-portfolio = v2.
- **P3 algorithm:** sort `(score DESC, tier_rank DESC, triggered_at ASC, signal_id ASC)` [deterministic, no clock/random]; greedy admit under ONE portfolio_lock with a running tally: one-per-symbol · long/short balance (NEW, inert default) · shared concentration (P4) · per-strategy cap (reuse) · `risk.approve` (reuse) · `fm.reserve` (reuse) · place (reuse, incl. FIX-067/throttle/FIX-070). Counts+capital are AUTO reservation-aware via the primitives; only NEW running state = shared-concentration tally + batch's own symbol/direction sets.
- **P4 shared concentration cap (NEW):** portfolio-wide `deployed + cand.margin ≤ max_portfolio_deployment_pct × total` (deployed from `fm.get_snapshot`, reservation-aware). COMPOSES with per-sector 0.40 (per-sector vs portfolio-wide; both must pass; no duplication). Default INERT (null/1.0 → byte-identical). Do NOT silently rewrite gate 8 (the batch tally closes the sector TOCTOU as a side benefit, but any gate-8 change is a separate flagged decision).
- **P5 idempotency:** buffered candidate is already-dequeued + still holds `_claim_in_flight(symbol)` + unique signal_id PK. **v1 does NOT carry across windows** (admit-or-reject within the window; reject releases claim + sets status exactly like FCFS) → no new duplicate window. Claim key = signal_id + the symbol claim; `gate_state` precedent (`state_store.py:2659`, "re-add of same signal_id does not raise") for any future cross-window carry.
- **P6 flag/shadow/enforce:** NEW `PortfolioAllocatorConfig` (extra=forbid, default-off). OFF = fused path, buffer never entered = BYTE-IDENTICAL. SHADOW = fire-and-forget guarded emit at `:904`, async observer computes would-be ranked set vs a start-of-window snapshot + logs REGRET (NEVER reserve/place; ZERO added live latency). ENFORCE = batch worker governs. **Honest caveat: the shadow counterfactual is APPROXIMATE** (FCFS mutates capital/counts as it runs → snapshot replay can't reproduce the live interleaving); REGRET is DIRECTIONAL, needs several sessions.
- **P7 no-late-entry:** window short + ≪ 60s expiry; placement re-anchors on fresh LTP (FIX-067 `:858-882`) → no stale entry; window length = shadow-tuned open Q.
