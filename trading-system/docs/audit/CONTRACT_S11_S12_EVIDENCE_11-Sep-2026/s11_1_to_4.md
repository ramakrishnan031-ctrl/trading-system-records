### Classes (the "defined but never read" vs "read but overridden" distinction)

- **READ-EFFECTIVE** — read on the live path; its value changes behaviour.
- **READ-COINCIDENT** — read and binding, but numerically equal to a global that binds at the same instant.
- **READ-OVERRIDDEN** — read, but a different value wins (a sentinel resolves to a global or a cache, or a global floor is checked first).
- **READ-UNREACHABLE** — read only inside a branch that current config or live data never enters.
- **READ-NON-BINDING** — read and evaluated, but it cannot bind at current values.
- **READ-DISPLAY-ONLY** — read only by dashboard, report or status code; no trading-path reader.
- **WRITTEN-NEVER-READ** — no reader beyond the schema declaration and its validator.
- **ABSENT** — not in the YAML; the schema default applies.
