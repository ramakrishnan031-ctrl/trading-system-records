**Original design report (trigger vs guarded-method, schema verdict, illegal proof, validation, D-1 relation, parity) — detail below + in the design doc.**

**Gap:** `trades.status` CHECK (schema.sql:158-161) validates the value SET, NOT transitions ⇒ raw UPDATEs can reopen a terminal row (proof: `order_manager.update_trade_status(id,"OPEN")` on a CLOSED trade succeeds on HEAD; real race = `kill_switch._mark_trade_exiting` U8 vs an exit fill ⇒ CLOSED→EXITING).

**States:** non-terminal = PENDING_FILL/PENDING/UNKNOWN_IN_FLIGHT/OPEN/PARTIAL/EXITING; terminal(absorbing) = CLOSED/CLOSED_MANUAL/FAILED/CANCELLED/REJECTED*. `PARTIAL` = schema-legal but **no live writer** (readers only). **INVARIANT = terminal-LOCK** (illegal iff OLD.status terminal AND status changes) — NOT a full matrix (a matrix would over-strictly break EXITING→CLOSED/recovery/OPEN↔PARTIAL). Legal edges incl. ★H-2 EXITING→CLOSED (close_trade accepts EXITING, order_manager.py:544), EXITING→OPEN (revert_exiting_to_open), EXITING→CLOSED_MANUAL.

**Raw-UPDATE inventory:** 6 state_store DAO methods + sl_breach + check_vm_state = ALREADY guarded (from-state in WHERE). **9 UNGUARDED (illegal-capable):** U1 `order_manager.update_trade_status` (639, GENERIC, 4 callers: order_placer 959/1319/1875/4301) · U2 `record_entry_fill`→OPEN (397) · U3 `close_trade`→CLOSED (598, Python pre-check only = non-atomic TOCTOU = D-1) · U4 order_placer:3685→EXITING · U5 reconciler:1961→FAILED · U6 eod_squareoff:830→CANCELLED · U7 structure_exit:354→EXITING · U8/U9 kill_switch 962/1275→EXITING. **All except U3 already try/except their UPDATE** (abort degrades gracefully); U3's caller catches only `ValueError` (order_placer.py:2249).

**SCHEMA VERDICT (decisive):** `executescript(schema_sql)` runs **UNCONDITIONALLY every boot** (state_store.py:367, after conditional migrations). ⇒ a **`CREATE TRIGGER IF NOT EXISTS`** is a **behavior-only pure-add: NO version bump, NO MIGRATION_TABLES rebuild** (a trigger is a standalone object — the "IF NOT EXISTS can't alter a table" limit that forces rebuilds doesn't apply; like the existing CREATE INDEX). Keep EXPECTED_SCHEMA_VERSION=41, trailing INSERT '41', 41==41 passes. Survives a future `trades` 12-step rebuild because executescript re-applies it AFTER migrations. **⇒ FITS Wave-5 no-schema-change.** Caveats: (a) convention has bumped the marker on every prior schema.sql change — not bumping is a defensible departure; IF bumped for traceability it must sequence w/ P1's pending v42; (b) RAISE(ABORT)→`sqlite3.IntegrityError` (not ValueError). Guarded-method = truly 0 schema but only as strong as routing all 9 (future raw UPDATE re-opens gap).

**RECOMMENDATION = HYBRID:** (1) trigger `trg_trades_terminal_status_guard` `BEFORE UPDATE OF status … WHEN OLD terminal … CASE WHEN NEW.status<>OLD.status THEN RAISE(ABORT)` — keystone, catches all 9 + future writers, no-bump; `UPDATE OF status`+`NEW<>OLD` ⇒ the 3 financial-backfill writers + idempotent writes pass untouched. (2) `close_trade`→atomic CAS (terminal-lock WHERE + rowcount winner, release once) OR catch IntegrityError→translate to existing ValueError path = **this is also D-1's core fix**; build together. Strict-min cut = trigger-only (broaden U3 caller except). Purist-no-schema cut = guarded-method (update_trade_status first).

**Validation:** real StateStore/OrderManager; (A) illegal REJECTED matrix terminal×writers + RED baseline (generic-setter reopen succeeds on HEAD) · (B) EVERY legal edge ALLOWED incl. ★EXITING→CLOSED/OPEN/CLOSED_MANUAL + financial-backfill-on-CLOSED must succeed + idempotent · (C) D-1 concurrent-finalizer race · (D) full regression.

**Parity:** single mode-agnostic path (order_placer→order_manager→state_store; `mode` is a column tag, paper fills sim at adapter `_paper_fills`, no writer forks on mode).
